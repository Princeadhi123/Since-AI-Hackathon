Setup

01The whole demo in one picture

What to do

Follow this path: ask a question -> check the form -> choose an owner -> create a plan -> get approval -> render -> download -> repeat.

What you get

A written request becomes a governed, frozen report. Repeating the same approved scope can return the existing plan: REUSE.

What this proves

The demo joins natural-language intake, human decisions, source-backed reports, and reuse.

RememberThe business data and roles are synthetic. The LLM is real, but it does not calculate the report or approve anything.

Setup

02Install once on each tester's computer

What to do

In PowerShell, clone the project and install it. If you already have this clone, use its folder and skip the first two commands.

git clone https://github.com/Princeadhi123/Since-AI-Hackathon.git
cd Since-AI-Hackathon
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[ui,llm,dev]"

What you get

Installation finishes without an error. Your project now has a .venv folder.

What this proves

This computer has the software needed to run the demo; this is not yet an LLM test.

RememberPython 3.11+ and internet are required. Do not edit the source workbook or frozen evidence files.

03Connect Snowflake before starting the app

What to do

Obtain a valid, scoped Snowflake PAT privately. Your Snowflake user must allow this computer's public outgoing IP. Enter these commands in the PowerShell you will launch from.

$env:LLM_PROVIDER = 'snowflake'
$env:SNOWFLAKE_ACCOUNT_HOST = 'TNRTNCL-SX96827.snowflakecomputing.com'
$env:LLM_MODEL = 'claude-sonnet-4-6'
$cortexToken = Read-Host 'Snowflake PAT' -AsSecureString
$env:SNOWFLAKE_PAT = [System.Net.NetworkCredential]::new('', $cortexToken).Password

What you get

The token prompt hides what you paste. The commands finish without printing the token.

What this proves

You supplied local configuration. A successful live request is still needed to prove access.

RememberSame Wi-Fi is not a credential. Never share the PAT in Git, chat, screenshots, or slides. No model deployment is needed.

Setup

06Read the status: what happens next?

What to do

Use the status to choose your next click. llm = extraction succeeded; pending = waiting; approved = ready to render; rendered = frozen report available; REUSE = existing approved scope found.

What you get

Pending: choose an approver. Approved: click Render frozen report. Rendered: inspect and download. REUSE: check the returned plan ID and existing result.

What this proves

Extraction, approval, rendering, and reuse are different steps, not one automatic AI action.

RememberREUSE is not a failure. An approved-but-not-rendered reused plan still needs rendering; a rendered reused plan already has a frozen result.
